Required Headers: Tum endpoint'ler (system-admin haric) X-Tenant-ID header'i gerektirir. Lokalizasyon icin Accept-Language (tr-TR, en-US) kullanilabilir.
Admin Endpoint Convention (Openspec): Tum admin panel endpoint'leri /api/admin/ prefix'i altinda bulunur. JWT token'da role: super_admin | admin ve tenant_id zorunludur. Endpoint'ler tenant_id ile scope'lanir.
